# PRGI Title Verification System

A prototype system for automatically verifying proposed publication titles against existing titles.

## Features

- Title similarity detection
- Phonetic matching
- Fuzzy string matching
- Restricted word validation
- Prefix and suffix checks
- Periodicity detection
- Multilingual semantic similarity
- Verification probability
- Application tracking

## Tech Stack

- Python
- SQLite
- RapidFuzz
- Phonetic matching
